# ALMATY.GG — Лендинг для платформы бронирования компьютерных клубов

**Дата:** 2026-05-14
**Тип:** Дизайн-спецификация лендинг-страницы (MVP)
**Стек:** Static HTML + CSS + JS
**Локализация:** Русский (только)

## Контекст и цель

В Алматы много компьютерных клубов, но нет единой платформы для онлайн-бронирования.
Платформа ALMATY.GG (рабочее название) должна объединять клубы города и позволять игрокам
находить и бронировать места онлайн.

Этот документ описывает **лендинг-страницу** — первую точку контакта с игроками (B2C).
Полная платформа (личный кабинет, оплаты, B2B-кабинет для клубов) — вне скоупа этого
спека. Лендинг — статический одностраничник, который продаёт идею и демонстрирует
будущий продукт через мок-данные.

## Целевая аудитория

**Игроки/геймеры в Алматы**, которые:
- Хотят быстро найти ближайший компьютерный клуб
- Готовы платить за удобство онлайн-бронирования (вместо звонков и очередей)
- Возрастная группа: 16–30 лет
- Привыкли к мобильным интерфейсам, ценят скорость

## Критерии успеха

1. Пользователь за 5 секунд понимает: «здесь можно забронировать комп. клуб в Алматы»
2. Лендинг отображается корректно на desktop (1440px), tablet (768px), mobile (375px)
3. Все интерактивные элементы работают: nav, поиск-форма, карточки клубов, модалки
4. Загрузка < 1 секунды на 4G (без тяжёлых ассетов)
5. Стилистика однозначно «геймерская/cyberpunk» — отличает от обычных booking-сайтов

## Архитектура

### Файловая структура

```
C:\ClaudeCode\
├── index.html       (разметка + якоря секций)
├── styles.css       (все стили, design tokens в :root)
├── script.js        (mock-данные клубов + интерактив)
└── docs\superpowers\specs\
    └── 2026-05-14-almaty-gg-landing-design.md
```

**Решение — 3 отдельных файла** (а не single-file): легче навигировать, проще
расширять, кэш браузера для CSS/JS. Размер каждого файла останется управляемым
(< 500 строк).

### Зависимости

- **Google Fonts**: Inter (400, 500, 600, 700) + JetBrains Mono (400, 500)
- **Иконки**: inline SVG (без иконочных шрифтов и внешних библиотек)
- **Изображения клубов**: плейсхолдеры через градиенты + CSS (без внешних фото в MVP)
- Никаких CDN, никаких build-инструментов

### Без бэкенда

Все формы и кнопки бронирования показывают модальное окно с подтверждением — это
демонстрационный лендинг. Никаких реальных запросов, без localStorage (кроме, возможно,
последнего поиска — опционально).

## Визуальная система

### Цветовые токены (CSS variables)

```css
:root {
  /* Фоны */
  --bg-base:      #0a0a0f;   /* основной фон */
  --bg-surface:   #14141c;   /* карточки, header */
  --bg-elevated:  #1c1c28;   /* hover-state, модалки */

  /* Текст */
  --text-primary:   #f0f0ff;
  --text-secondary: #a0a0b8;
  --text-muted:     #60607a;

  /* Акценты */
  --neon-cyan:    #00f0ff;   /* primary CTA, ссылки, glow */
  --neon-magenta: #ff2e9a;   /* secondary, акценты */
  --neon-yellow:  #fef300;   /* highlight, цены */

  /* Семантика */
  --border:       rgba(0, 240, 255, 0.15);
  --border-hover: rgba(0, 240, 255, 0.4);

  /* Glow */
  --glow-cyan:    0 0 20px rgba(0, 240, 255, 0.4);
  --glow-magenta: 0 0 20px rgba(255, 46, 154, 0.4);
}
```

### Типографика

- **Inter** (sans-serif) — основной текст, заголовки секций, body
- **JetBrains Mono** — цены, рейтинги, числа в стате, теги, лого «.GG»
- H1: 64px / 1.1 / 700 (desktop), 36px (mobile)
- H2: 40px / 1.2 / 700 (desktop), 28px (mobile)
- H3: 24px / 1.3 / 600
- Body: 16px / 1.6 / 400
- Small: 14px / 1.5 / 400

### Spacing scale

`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 / 128` px

### Эффекты

- **Фоновая сетка**: тонкий CSS-grid через `background-image: linear-gradient(...)` с rgba(0,240,255, 0.04)
- **Scanline** в hero: линейный градиент с прозрачностью + animation translateY
- **Glow на CTA**: `box-shadow` с blur и неон-цветом
- **Hover на карточках**: `transform: translateY(-4px)` + `box-shadow: var(--glow-cyan)`
- **Glitch на H1 (одно слово)**: subtle anchor через `::before/::after` с RGB offset, активируется на load
- **Smooth transitions**: 200–300ms на всех hover-стейтах

## Поведение / JS

### Список интеракций

1. **Sticky header** — при `scrollY > 50` добавляется класс `.scrolled` (фон + blur)
2. **Smooth scroll** — клик по nav-ссылкам с `href="#section"` плавно прокручивает
3. **Mobile menu** — кнопка hamburger toggle класс `.menu-open` на body
4. **Поисковая форма submit** — `preventDefault()`, показывает модалку «Найдено N клубов в [Район] на [Дата] в [Время]» (моковая логика)
5. **Карточки клубов** — рендерятся из массива `clubs` в JS (`document.createElement`)
6. **Клик «Забронировать»** — модалка «Забронировано в [Клуб] на [текущая дата] · QR-код придёт на email» (демо)
7. **Модалка** — overlay + центральная карточка, закрытие по Esc / click outside / кнопке X
8. **Glitch-анимация H1** — запускается один раз через 500мс после load

## Доступность (a11y) — минимум

- Семантические теги: `<header>`, `<main>`, `<section>`, `<footer>`, `<nav>`
- Alt-текст на всех визуальных элементах (или `aria-hidden` где декор)
- Контраст по WCAG AA: текст на тёмном фоне ≥ 4.5:1
- Focus-стейты у кнопок и ссылок (cyan outline)
- Модалка: trap focus + Esc-закрытие
- `lang="ru"` на `<html>`

## Тестирование (ручное)

1. **Десктоп 1440px** — все секции отображаются, hover-эффекты работают
2. **Tablet 768px** — сетки перестраиваются, поиск-форма читабельна
3. **Mobile 375px** — hamburger меню работает, карточки стакаются
4. **Поиск-форма** — заполнить и отправить → видна модалка
5. **Карточка клуба** — клик → модалка бронирования
6. **Smooth scroll** — клик по nav-пунктам ведёт к секциям
7. **Header scroll** — фон меняется при скролле
8. **Keyboard nav** — Tab/Shift+Tab проходят по интерактивам, Esc закрывает модалку

## Out of scope (явно НЕ делаем в этом MVP)

- Реальная регистрация/авторизация
- Личный кабинет игрока или клуба
- Реальная оплата (Kaspi, Stripe)
- Бэкенд / база данных / API
- Многоязычность (KK, EN)
- B2B-кабинет для владельцев клубов (только заглушка-ссылка)
- Турниры, события, лидерборды
- Реальные фотографии клубов (только градиент-плейсхолдеры)
- Карта Алматы (можно итеративно)
- SEO-оптимизация (meta-теги — базовые)
- Аналитика (Google Analytics и т.п.)
